Feature

Claude artifacts can now be installed as desktop apps (beta, Mac and Windows)

Installed artifacts open in their own window on Claude for Mac and Windows on all plans; no regional restriction is stated, so it applies in Germany.

Three permission levels: browser-equivalent default, app permissions (notifications, global shortcuts), and full computer access. Team has it on with full access off; Enterprise is off until an owner enables it. Permissions must be re-approved after every update, and Anthropic does not review apps. Usage counts toward plan limits. Not available to HIPAA-ready orgs.
Why it matters: Your own small tools (dashboards, trackers) can live as apps without hosting. For client or Sopra use, full computer access is a security review topic.
Action: Update the Claude desktop app and install one of your own artifacts. For Sopra, do not enable full access before IT security has looked at it.
Take: Handy for personal tools. Full computer access for unreviewed apps is a risk you should not wave through at a client.
Your plans: Claude Max: yes. Sopra work access: off by default until an owner enables it.

Workspace

Google Workspace MCP servers are GA; MCP becomes mandatory for agents on 1 Feb 2027

Chat, Gmail, Calendar, Docs, Drive, Sheets, Slides and Tasks MCP servers are generally available (rollout up to 10 days); no region limit is listed.

Standard tier is capped at 5,000 requests per day per project per product. From 1 Feb 2027 agents must use MCP and direct REST calls fall under Standard quotas; billing for the Scaled tier starts 1 Apr 2027. Since 11 Nov, MCP servers reject OAuth clients not marked as AI agent clients. On 26 Nov seven more Gmail tools (send_message, reply, create_filter) went GA.
Why it matters: If you wire Claude Code or a homelab agent to Gmail, Drive or Calendar, the old direct-API route is on a deadline. Consulting clients on Workspace will ask about this.
Action: Re-create any OAuth client used by agents as an agentic client and move agent access to the MCP servers before February.
Take: Sensible move by Google, but it is also a metering hook: billing arrives in April.
Your plans: Google AI Pro (personal Google account): check whether your account gets access, the notes target Workspace and Cloud projects.

Open weights

Inkling 2 Mini lands in Ollama (0.40.18); about 32 GB memory suggested

Thinking Machines' Inkling 2 Mini can be run locally via Ollama on Windows and Linux; as a local model there is no data-processing question, and cloud hosting via Fireworks is also offered.

Ollama suggests 32 GB of shared or graphics memory as a guideline. Fireworks lists Inkling 2 Mini at $0.15 per million input and $0.50 per million output tokens, Inkling 2 Small at $0.30 and $1. The model reuses parts of its network in loops to get reasoning with less memory (The Neuron).
Why it matters: It fits a 32 GB GPU or two smaller cards in your homelab.
Action: Run ollama pull inkling-2-mini after updating Ollama and compare it with your current local default on two or three real tasks.
Take: Interesting architecture, but no independent benchmarks yet. Test, do not switch.
Your plans: Local only (free), or paid Fireworks API.
